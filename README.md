# Start Creative Digital — Projeto inspirado na referência visual

## Requisitos
- Node.js 18+
- VS Code

## Instalação

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite, normalmente:
http://localhost:5173

## Build de produção

```bash
npm run build
npm run preview
```

## Onde personalizar

### Cores
Edite:
- `tailwind.config.js`
- `src/index.css`

### Textos e dados
Edite:
- `src/data/siteData.ts`

### Seções
Os componentes estão em:
- `src/components/`

### WhatsApp
Procure por:
`5500000000000`

e substitua pelo número real no formato internacional.

### Imagens
As imagens de exemplo estão em URLs do Unsplash dentro de:
`src/data/siteData.ts`

Para produção, recomenda-se baixar suas imagens e colocá-las em `public/images`.

## Observação
O projeto é uma implementação própria inspirada na referência visual enviada pelo usuário, com identidade visual escura em azul e verde e estrutura de diretório digital.
